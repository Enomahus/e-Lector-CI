# Introduction

Authorization engine to handle permissions.
This is the core project for permissions handling.

## Dependencies

- DotNet core 10

## Usage

To use this project, call [AddPceaCoreNetAuthorization](./ConfigureServices.cs) to add services in dependency injection.

## Example

See [Demo](https://apollo-ssc.visualstudio.com/Apollo.Core/_git/Apollo.Core.Net.Authorization.Demo) project to get an overview on how to use and expand it.
